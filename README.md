Sobre o projeto

Site simples para adicionar e remover tarefas.

Tecnologias utilizadas
HTML: estrutura do site.
CSS: estilização.
JavaScript: funcionalidades.
Funcionalidades
Adicionar tarefas.
Remover tarefas ao clicar nelas.
Avisar quando o campo estiver vazio.
Limpar o campo após adicionar uma tarefa.
Como executar
Baixe os arquivos.
Coloque todos na mesma pasta.
Abra o arquivo index.html no navegador.
Objetivo

Projeto desenvolvido para praticar HTML, CSS e JavaScript e aprender a criar um site interativo.
